# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
争议处理单按票生成：`dispute_id` 为 `票号+争议依据版本+买家主张+证据行号` 的确定性指纹；`dispute_amount=|生效应付−买家主张|`，`hold_amount=min(dispute_amount, 待付)`，`payable_amount=待付−hold_amount`。证据行号必须命中该票计价版本的 `lines`，否则入待处理（EVIDENCE_UNLINKED）；票在 `version_conflicts` 中时按 BRANCH_UNCLOSED 待处理；指纹重复按 DISPUTE_DUPLICATE 待处理，均不占款、不封存。
归档封存保存逐版证据、隔离原因、争议处理单/待处理队列和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。
